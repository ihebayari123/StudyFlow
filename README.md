# 📘 Description du projet

**StudyFlow** est une plateforme web de gestion e-learning développée dans le cadre du projet **PIDEV – 3ème année ingénierie** à **Esprit School of Engineering** durant l’année universitaire **2025–2026**.

Cette application a pour objectif de faciliter la gestion des activités pédagogiques et d’améliorer l’expérience des étudiants grâce à une plateforme moderne, intuitive et interactive.

Le projet intègre plusieurs modules permettant la gestion :
- des utilisateurs,
- des cours,
- des chapitres,
- des quiz,
- des produits,
- des commandes,
- des événements,
- ainsi qu’un module intelligent de gestion du stress basé sur l’intelligence artificielle.

---

# 🎯 Objectifs

- Développer une plateforme e-learning complète et moderne
- Faciliter la gestion des cours et des utilisateurs
- Offrir une expérience utilisateur intuitive et responsive
- Intégrer des outils de suivi pédagogique et statistique
- Mettre en place des fonctionnalités innovantes basées sur l’IA
- Aider les étudiants à mieux gérer leur stress et leur productivité

# 🏗️ Architecture du projet

Le projet suit l’architecture **MVC (Model - View - Controller)** proposée par Symfony.

### Structure générale :
- **Model** → Gestion des données et de la base de données
- **View** → Interfaces utilisateur avec Twig
- **Controller** → Traitement des requêtes et logique métier

### Particularités :
- Séparation claire entre backend et frontend
- Gestion des assets avec Webpack Encore
- Intégration de scripts Python pour les fonctionnalités IA
- Organisation modulaire du projet

---

# 🔄 Méthodologie de développement

Le projet a été développé en utilisant la méthodologie **Agile Scrum**.

### Organisation :
- Répartition des tâches par modules
- Développement collaboratif via GitHub
- Gestion des versions avec Git
- Travail en équipe par sprints
- Réunions de suivi et validation continue

# 🤖 Intégration de l’intelligence artificielle

StudyFlow intègre des fonctionnalités intelligentes permettant :
- l’analyse du stress étudiant,
- des recommandations intelligentes,
- l’assistance à la productivité,
- l’amélioration du bien-être des utilisateurs.

Les modules IA ont été développés avec Python et des modèles de Machine Learning.
